- 기능: FN-HLT-003 기록 내용의 투약 기록 규칙("하루 N회를 채우면 기록 내용에 추가"). 서버는 항목·날짜당 1행에 체크마다 `CMPTN_CYCL`을 올리고, 기록 내용 조회는 이미 N회 채운 날만 돌려준다. 다만 기록 내용에서 취소하면 1회만 내려가 명세("그날 완료 기록 취소")와 다르다. 프론트에서 숨기거나 DELETE를 여러 번 보내지 않고 서버에서 맞춘다
- 바꿀 것: ① `GET /pets/{petSn}/care-completions`는 투약 항목이면 그날 `CMPTN_CYCL`이 `dayMdcnNmtm`을 채운 날만 돌려준다 — 이미 있음(항목·날짜당 1행에 체크마다 `CMPTN_CYCL`을 올리는 방식과 `todayCmptnCnt`는 그대로) ② 기록 내용에서 투약 취소 시 그날 그 항목의 완료 기록을 한 번에 지우는 API ③ 케어리스트 투약 [마지막 1회 취소]에 쓸 그날 완료 기록 번호가 목록 응답에 없다. ②와 함께 취소 방식을 정한다
- 기다리는 것: 없음 (토탈 케어리스트 API는 develop 병합됨)
- 완료 조건: 하루 2회 투약 항목을 1회만 체크하면 기록 내용 조회에 안 나오고, 2회 체크하면 1건으로 나온다. 일괄 취소하면 그날 기록이 모두 지워지고 `todayCmptnCnt`가 0이 된다
- 연결 남음: FN-HLT-003-12 (프론트 연결 케어리스트 기록 내용 아이콘 취소·투약 [마지막 1회 취소], 프론트 저장소에서 /start — 마일스톤 "SCR-HLT-003 케어 캘린더 · 투약 취소 API 연결")
