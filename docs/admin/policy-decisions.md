# 관리자 페이지 정책 결정 (팀 공유용 초안)

2026-10-30, LJS 작성. 팀 합의 전 제안이다. 합의되면 요구사항정의서·도메인 문서·DB에 반영하고, 반영한 항목은 표의 "반영" 칸에 표시한다.

## 배경

- 관리자 요구사항(REQ-ADM-001~013)에는 화면설계·기능명세가 없다. 09-06 팀장 결정으로 "사용자 도메인 확정 후 착수"였다.
- DMS 최신 문서를 다시 읽고 관리자가 관리할 항목을 뽑았다. 대상은 요구사항정의서 v0.9.0, IA 구조도 v0.2, 정책결정관리서 v0.2, 9개 도메인의 기능명세서·화면설계서다. 이어서 `db/20261029_create_tables_v0.10.sql`과 대조했다.
- 그 과정에서 문서끼리 어긋나거나 정해지지 않은 것을 아래와 같이 정했다.

- 신고는 독립 대분류로 둔다.
